# MyStockViewer - Stock K-Line Data Service
This repository contains the complete and verified source code for the MyStockViewer application.
## Deployment
1. Install Git, Docker, and Docker Compose on your server.
2. Clone this repository: `git clone https://github.com/HiGodfather/MyStockViewer.git`
3. Navigate into the directory: `cd MyStockViewer`
4. Build and start the service: `sudo docker compose up --build -d`
5. Access the application at `http://<your_server_ip>:8080`
